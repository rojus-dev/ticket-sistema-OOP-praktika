# IT problemų registravimo ir sekimo sistema

Laravel pagrindu sukurta sistema IT problemų registravimui ir sekimui.

## Funkcionalumas
- vartotojų autentifikacija
- problemų registravimas
- problemų statusų valdymas
- komentarai
- el. pašto pranešimai
- PDF ataskaitos generavimas
- PDF siuntimas el. paštu
- kategorijų valdymas
- statistikos grafikas

## Naudotos technologijos
- PHP
- Laravel
- MySQL
- Tailwind CSS
- Chart.js
- DomPDF
